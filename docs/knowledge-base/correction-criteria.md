# Critères Officiels de Correction - TEF IRN

## 1. Expression Écrite - Section A (Message court)
*   **Capacité à transmettre des informations** : L'utilisateur doit répondre à tous les points de la consigne (ex: inviter, remercier, donner des nouvelles).
*   **Cohérence** : Le message doit être structuré logiquement.
*   **Lexique** : Utilisation d'un vocabulaire de base adapté à la situation.
*   **Morphosyntaxe** : Maîtrise des structures grammaticales simples (présent, passé composé, futur proche).

## 2. Expression Écrite - Section B (Argumentation)
*   **Capacité à convaincre** : Utilisation d'arguments pertinents pour défendre un point de vue.
*   **Organisation** : Présence de connecteurs logiques (donc, car, mais, de plus).
*   **Étendue du lexique** : Capacité à varier le vocabulaire pour éviter les répétitions.
*   **Précision grammaticale** : Maîtrise du subjonctif, du conditionnel et de la syntaxe complexe.

## 3. Grille de Score
*   **A1 (0-100 pts)** : Compréhension très limitée, phrases isolées.
*   **A2 (200 pts)** : Peut décrire des tâches quotidiennes simples.
*   **B1 (300 pts)** : Peut raconter un événement, un espoir ou un but.
*   **B2 (400 pts)** : Peut argumenter de façon efficace et nuancée.
